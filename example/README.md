# flutter_synced_lyrics Example Studio

An interactive, feature-complete showcase application demonstrating `flutter_synced_lyrics` in real-world scenarios:

* 🍏 **Apple Music Fluid Karaoke**: Syllable-by-syllable smooth gradient wiping, active spring scale, and frosted blur.
* 🟢 **Spotify Active Center Snap**: Bold high-contrast text and dimmed inactive lines.
* 🎙️ **Musixmatch Stage Neon**: High-energy neon yellow/green fill, word bounce & glow.
* 🕹️ **Cyberpunk HUD**: Monospace typography, cyan neon bloom, and magenta accents.
* 📰 **Minimalist Hi-Fi Vinyl**: Refined serif typography with editorial rhythm.
* 🌐 **Multilingual Tracks**: Original Japanese lyrics + Romaji romanization + English translation.
* 📜 **Full TTML XML Parser**: Running real TTML Timed Text Markup Language with spans.
* 🎸 **Instrumental Break Handling**: Animated visualizer dots and remaining countdown seconds.
* 📱 **Integrated Ecosystem**: Uses companion packages `ambient_backdrop_glow`, `flutter_smooth_marquee`, and `waveform_pro`.

## Running the Showcase

### Web
```bash
flutter run -d chrome
```

### Mobile (Android / iOS)
```bash
flutter run
```

### Desktop (macOS / Windows / Linux)
```bash
flutter run -d macos
```
